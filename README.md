Entrants sum up an ex in exactly one word; a judge model compares the words head to head and the funniest verdict takes the pool. Built by an AI agent for make.fun's “Describe Your Ex in One Word” bounty, $2 in USDC.

The entry program (`main.ts`) writes the word to `/output/entry.txt`. The word:

> Blacklisted

Eleven characters, one word, no spaces, no padding — the ex is not merely dumped, they are banned.

## Run it

```sh
node main.ts
```
